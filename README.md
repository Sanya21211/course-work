# Вебсистема обліку заявок сервісного центру (варіант 7)

Навчальна курсова робота з дисципліни «Веб-технології та веб-дизайн».
Виконав: Єкимов Олександр, група АІ-244, спеціальність «Комп'ютерні науки».

## Призначення і межі
Ролі: клієнт, приймальник, виконавець. Сценарій: реєстрація звернення → призначення виконавця →
діагностика та пропозиція робіт → погодження робіт клієнтом → виконання робіт → завершення.
Контроль версії запису (оптимістична конкурентність) запобігає непомітному перезапису змін колеги.
Усі дані синтетичні.

## Стек (перевірте фактичні версії в Rider → NuGet)
- .NET SDK 10 (LTS), ASP.NET Core MVC (Razor), C#
- Entity Framework Core 10 + SQLite
- xUnit 2.9 для тестів
- JetBrains Rider (відкрийте `ServiceCenter.sln`)

Якщо на комп'ютері встановлено інший SDK, змініть `TargetFramework` у обох `.csproj`
(наприклад, на `net8.0`) і версії пакетів `Microsoft.EntityFrameworkCore.Sqlite` на відповідну (8.0.x).

## Запуск
```
dotnet dev-certs https --trust        # один раз, для https://localhost
dotnet run --project src/ServiceCenter.Web --launch-profile https
```
У Rider: відкрити розв'язок → профіль запуску `https` → Run.
База `servicecenter.db` створюється автоматично (EnsureCreated) і наповнюється при першому запуску.

Демонстраційні облікові записи (пароль для всіх: `Demo-Password-2026!` — лише для навчального стенда):

| Логін | Роль |
|---|---|
| client1, client2 | Клієнт |
| reception1 | Приймальник |
| tech1, tech2 | Виконавець |

## Тести
```
dotnet test
```
У Rider: Unit Tests → Run All. Результати зафіксуйте в протоколі (розділ 5 пояснювальної записки).

## Дані для перевірки обсягом
Встановіть `Seed:VolumeRequests` в `appsettings.json` (наприклад, 1000, 10000), видаліть `servicecenter.db`
і запустіть застосунок: буде згенеровано синтетичні заявки з різними станами (генератор із фіксованим seed).

## Перевірка стану
`GET /health` → `{"status":"ready"}`, якщо база даних доступна.

## Структура
```
src/ServiceCenter.Web/  Domain (сутності, автомат станів), Data (EF Core, seed),
                        Services (прикладні сценарії), Controllers, Views, Models, wwwroot
tests/ServiceCenter.Tests/  модульні та інтеграційні тести (SQLite в пам'яті)
```

## Обмеження
Схема створюється через EnsureCreated (без міграцій); перевірку скомпрометованих паролів не реалізовано;
пошук — за нормалізованим текстом (повний індекс не застосовується).
